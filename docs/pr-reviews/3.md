## Summary

- Scope: 画像生成パイプラインを `kind: 'canvas' | 'svg'` の discriminated union（`src/lib/render/types.ts`）に部品化。satori による新フォーマット「カード (SVG)」（`renderers/svgCard.tsx`、`satoriEngine.ts` で Noto Sans JP TTF を jsdelivr から fetch & キャッシュ）を追加。CSP に `script-src 'wasm-unsafe-eval'`、`public/hb.wasm`、プレビュー失敗時のエラー表示を追加。
- Risk: Medium — 新たな外部 CDN 依存（フォント）と CSP 緩和（`wasm-unsafe-eval`、WASM コンパイルのみ許可で eval は依然不可）を含む。
- Positives:
  - `DocumentRenderer` の union 化は拡張ポイントとして綺麗で、既存 canvas レンダラーは `kind: 'canvas'` 追加のみで挙動不変。
  - プレビューはオフスクリーン canvas に描画してからシーケンス番号で最新のみブリット。非同期レンダーの競合を正しく処理。
  - プレビュー失敗時に stale な画像を残さずエラー表示する改善を同梱。
  - 依存 `satori@0.33.4` は公開から日の浅い最新ではなく一つ前を採用（サプライチェーン考慮）。

## Concerns (Devin Review + 目視、計4件)

1. **[bug] 長文がSVGカードからはみ出す**: `svgCard.tsx` — 固定 fontSize のため長い本文/タイトルがカード外に溢れ、出力から失われる（canvas 版は `fitFontSize` で自動縮小）。
2. **[bug] フォント取得失敗がキャッシュに残る**: `satoriEngine.ts` — 初回 fetch 失敗時、rejected Promise が `fontCache` に残りリロードまで復旧しない。
3. **[bug] 本文の改行が消える**: `svgCard.tsx` — 通常の空白処理で `\n`・空行が潰れ、入力と異なる画像になる。
4. **[security] `frame-src https:` の緩さ**: `index.html` — 任意 HTTPS サイトの iframe 埋め込みを許可（本 PR の diff 行上の既存テンプレートポリシー）。

## Re-review (修正確認 — `69cb337` / `9233b34`)

- **[bug] 長文のはみ出し → 解決**: 取得済みフォントを `FontFace` 登録し `layout.ts` の `fitFontSize`（二分探索）でタイトル/本文を自動縮小。`overflow: 'hidden'` をルートに追加し、推定誤差による残オーバーフローもクリップ。`bodyAvailable` は上下 padding 双方を控除するよう修正済み。
- **[bug] フォントキャッシュ → 解決**: 失敗時に `fontCache = null` で次回リトライ可能。`FontFace.load()` を await してから `document.fonts.add` するため、初回描画の測定がフォールバックフォントで狂う問題も解消。
- **[bug] 改行消失 → 解決**: タイトル・本文に `whiteSpace: 'pre-line'`（改行・空行を保持しつつ空白は畳む）。
- **[security] frame-src → 解決**: `https:` を除去し `frame-src 'self'` に tightening（アプリ内に iframe 使用なし）。
- 検証: `npm run test`（tsc + eslint + vitest + build）ローカル green。CI `test` + Devin Review チェック green。satori 0.33.4 で `pre-line`/`overflow: hidden` の動作を Node 実機で確認済み（clipPath 生成を確認）。
